# 00i → OOi Scale

## No minus. No negative. One quadrant.

A normal coordinate system has 4 quadrants: `++, +-, --, -+`.
The OOi 7×7 has ONE quadrant. Everything is positive.

- X axis: Pillar 1 (Identity) → Pillar 7 (Continuity). All positive.
- Y axis: L1 (External) → L7 (Legacy). All positive.
- No cell is negative. No truth rate goes below zero.
- Empty = 0 (not yet answered). Verified = max (answered and confirmed).
- You start at 00i (the origin, zero-zero) and move toward OOi (maximum).
- There is no retreat. Only growth, or not-yet-grown.

Everything inside this grid is ≥ 0. The gradient from cyan (00i) to gold (OOi) is a one-way ramp. You don't go back. You fill, or you haven't filled yet.

## L0 — the view from above

L0 (blockchain.00i) looks DOWN at this grid and sees ALL of it — every cell, every truth.rate, every timestamp. L0 is the ledger that records the filling.

## theData.everywhere.truth.rate.

- **theData** — the content in every cell
- **everywhere** — flows through mesh, all perspectives, all objects
- **truth** — verified? confident? re-confirmed?
- **rate** — the pulse: 0% → 100%, NEVER negative

The truth rate is a one-directional measure:
```
0% ─────────────────────────────────────────────── 100%
empty    draft    review    verified    re-verified
nothing  started  checking  confirmed  re-confirmed
```

No cell ever goes to -1. A cell that was verified and is now stale doesn't become negative — it decays toward zero. Z (_archive) catches it. But it never goes below the floor.
