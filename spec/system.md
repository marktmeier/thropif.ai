# OOi — The Complete System

## The layers of the system

The hologram (L0-L7) is the object structure. But the system has more:

### 1. The Object — L0 to L7
The hourglass. 3,199 cells per object. 7 layers × 7 pillars × depth rings.
L0 is the blockchain view from above. L7.7 is the gold seal.

### 2. .mesh[Perspectives.skill.client.user]
The mesh is not just connections between objects — it carries **perspectives**.
Different viewers see the same object differently:

| Viewer | What they see | Through |
|---|---|---|
| **Perspective** | The full picture — all layers visible to their access level | L0 top-down |
| **Skill** | What capabilities/expertise this object provides | L3 wiring + L4 evidence |
| **Client** | What the client needs to know — product, safety, efficacy | L1 + L4 + L6 filtered |
| **User** | The end-user experience — what they feel, what they see | L1 + L6 |

The mesh carries the data. The perspective determines which data arrives.

### 3. .masks.layer.based.view
Masks filter visibility. Layer-based access control per viewer role:

```
.masks
  .project     — what this project's scope allows
  .company     — what this company can see (Meier Dynamics vs Meier Innovation Lab)
  .contacts
    .agent     — what an AI agent can access
    .drwalid   — what Dr. Walid (pharmacologist, partner) can access
  .supplier    — what a supplier (Pelin, raw material vendors) can see
```

Each mask is a **layer-based filter**:
- An agent mask might allow L1-L4 but lock L5-L7 (no commerce, no human impact, no legacy)
- A supplier mask allows L1-L2 (external + composition) but locks L3+ (rules, science, commerce)
- Dr. Walid's mask allows L1-L6 (clinical partner, sees impact) but L7 stays human-only
- The project mask scopes to one project's cells only

Masks stack. A supplier on project X sees: supplier mask ∩ project mask = only the cells visible to both.

### 4. .memory[time;OOi]
Memory has two axes:

- **time** — the temporal dimension. Every cell has a timestamp. Truth rate decays with time. Data flows from now → past → Z (archive). The 512-step gradient includes this: recent data is bright (high truth rate), old data dims.

- **OOi** — the memory IS the OOi structure. The hologram is not a view OF memory — it IS memory. Every cell is a memory cell. The 3,199 leaves per object ARE the object's memory. The vault, the Data Center, the session transcripts — they all map into OOi cells.

Memory is not a separate system. Memory is what happens when you fill the OOi cells over time.

### 5. functions octans
8 octants. The functional divisions of the 3D OOi space.

The Three 7s create a 3D coordinate: WHO (L1-L7) × WHAT (B/P/S/C/Pp/Ca/O) × WHERE (P1-P7).

Each axis can be above or below its midpoint (L4, pillar 4, P4):
- 2 × 2 × 2 = **8 octants**

```
Octant 1: WHO high + WHAT high + WHERE high  — deep trust, strategic, tech
Octant 2: WHO high + WHAT high + WHERE low   — deep trust, strategic, formula/product
Octant 3: WHO high + WHAT low  + WHERE high  — deep trust, operational, tech
Octant 4: WHO high + WHAT low  + WHERE low   — deep trust, operational, formula
Octant 5: WHO low  + WHAT high + WHERE high  — surface, strategic, tech
Octant 6: WHO low  + WHAT high + WHERE low   — surface, strategic, formula
Octant 7: WHO low  + WHAT low  + WHERE high  — surface, operational, tech
Octant 8: WHO low  + WHAT low  + WHERE low   — surface, operational, formula
```

But in OOi there are no negatives — so "low" means "closer to L1/P1/B" (the min) and "high" means "closer to L7/P7/O" (the max). The octants are 8 functional zones, not ± quadrants.

Each octant is a **function** — a natural cluster of activity:
- Octant where WHO=high + WHAT=Operations + WHERE=P6-TECH = **systems building** (Mark's core function)
- Octant where WHO=low + WHAT=Products + WHERE=P1-FORMULA = **new ingredient research** (early stage, surface level)
- Octant where WHO=high + WHAT=Community + WHERE=P4-BRAND = **brand loyalty teaching** (deep trust, community, brand)

The object exists (L0-L7).
The mesh carries it (perspectives, skills, clients, users).
The masks filter it (project, company, contacts, supplier, agent).
The memory grounds it in time (now → past → Z).
The functions cluster it into 8 octants (WHO × WHAT × WHERE above/below midpoint).
The scale measures it (00i → OOi, 512 steps, truth.rate).

All positive. No negatives. One direction: empty → filled → verified → permanent.
